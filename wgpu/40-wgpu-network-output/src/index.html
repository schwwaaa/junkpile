Network Output

Publish one authoritative wgpu frame through UDP/MPEG-TS, RTSP/TCP, or RTMP/FLV. A startup probe forces FFmpeg to create the output header before the app reports success, while bounded readback and writer queues keep the renderer independent from network failures.

connection model

Publisher and receiver are different roles

UDP sends directly to a receiver and needs no server. RTSP and RTMP publish into a running media server; VLC reads from that server afterward. Run the preflight before starting live frames.
