# Changelog

## 0.1.0

- Add native Windows Spout2 sender example.
- Port ShadeCore's Spout sender lifecycle through a C ABI bridge.
- Use SpoutDX and Direct3D 11 instead of requiring an OpenGL context.
- Add asynchronous wgpu readback, reusable BGRA buffers, bounded worker queue, adapter selection, orientation control, and drop telemetry.
