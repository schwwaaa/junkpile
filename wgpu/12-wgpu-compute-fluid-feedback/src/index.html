Compute Fluid Feedback

A real GPU fluid pipeline built from storage textures and WGSL compute passes. Velocity is advected, curled, pressure-projected, and used to transport HDR dye. The visual result can feed back into itself while the underlying velocity, pressure, divergence, and curl fields remain inspectable.

Simulation definition

The square fluid grid controls simulation detail. It is independent from the output definition. Eight RGBA16F field textures are maintained on the GPU.

A 2048² fluid uses roughly 256 MiB for its eight field textures before the output target and driver allocations. Increase pressure iterations and substeps carefully because every added pass touches the complete grid.
