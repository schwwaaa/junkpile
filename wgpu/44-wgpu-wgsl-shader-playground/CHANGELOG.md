# Changelog

## 0.1.0

- Create the native wgpu WGSL shader playground.
- Add an in-application source editor with line numbers and unsaved-change tracking.
- Add manual and debounced automatic compilation.
- Add Naga and wgpu validation with last-known-good pipeline retention.
- Add native Open, Save, and Save As dialogs.
- Preserve active preset and profile when a file is saved.
- Include twelve built-in stress-lab shaders and generated uniform controls.
- Define Spin as angular velocity in radians per second.
- Add pause, resume, and reset controls for shader time.
- Add native fullscreen output and high-resolution PNG export.
- Add GPU, FPS, frame-time, pipeline, and compiler diagnostics.
