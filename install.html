Installation guide

Install one example.
Run it locally.
Build the application.

You do not install all of Junkpile at once. Each example is an independent Tauri application. Choose one folder, install its local dependencies, run it, and build it from that folder.

1. Requirements 2. Get Junkpile 3. Choose an example 4. Run it 5. Build it 6. Verify Problems

Step 1

Install the required tools

Node.js and npm

Used for each example’s local frontend and Tauri scripts.

node --version
npm --version

Rust and Cargo

Used to compile the Tauri shell, native integrations, and wgpu renderer.

rustc --version
cargo --version

Platform build tools

Install the operating-system prerequisites listed below before running a project.

macOS

xcode-select --install

Use a current Rust toolchain and Node.js installation. macOS provides WKWebView; native wgpu uses Metal.

Windows

Install Microsoft C++ Build Tools with the Desktop development with C++ workload. WebView projects also require the WebView2 Runtime. Native wgpu uses Direct3D 12 when supported.

Linux

sudo apt update
sudo apt install build-essential curl wget file   libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev   patchelf libssl-dev libasound2-dev libvulkan1 vulkan-tools

Linux package names vary by distribution. The command above targets Ubuntu/Debian-style systems.

Step 2

Get the repository

A

Clone with Git

git clone https://github.com/schwwaaa/junkpile.git
cd junkpile
B

Or download the ZIP

Download the repository ZIP from GitHub, extract it, and open a terminal in the extracted junkpile directory.

Step 3

Choose one example

The repository is divided into three collections:

v1/

Tauri v1 applications using p5.js, WebGL, GLSL, browser media, and selected Rust integrations.

v2/

Tauri v2 WebView applications using current capabilities, APIs, dialogs, file workflows, and WebGL.

native-wgpu/

Rust-owned wgpu applications using WGSL, compute, native media bridges, 3D, and export systems.

Enter the folder for the example you want to run:

# Example: Tauri v1
cd v1/p5-tauri-single-template

# Example: Tauri v2
cd v2/p5-tauri-v2-single-template

# Example: native wgpu
cd native-wgpu/00-wgpu-surface-probe

Step 4

Install the example and run it

Run these commands from inside the selected example folder:

npm install
npm run dev
Use the local npm script. Do not rely on a globally installed Tauri CLI. Each project’s script selects the correct command and Tauri generation.

What should happen

First launch

Rust dependencies compile. The first run can take several minutes.

Application window

The selected standalone example opens after compilation succeeds.

Frontend edits

HTML, CSS, and JavaScript changes generally reload through the development server.

Rust edits

Changes under src-tauri/ trigger a native rebuild.

Step 5

Build the standalone application

npm run build

Build artifacts are normally written beneath:

src-tauri/target/release/bundle/
PlatformTypical output
macOSbundle/macos/*.app and, when configured, bundle/dmg/*.dmg
Windowsbundle/msi/*.msi or bundle/nsis/*.exe
Linuxbundle/appimage/*.AppImage, bundle/deb/*.deb, or another configured package

The exact bundle formats depend on the example’s Tauri configuration and the operating system used for the build.

Step 6

Verify the example before modifying it

□ The application opens without a panic or blank window.
□ The expected shader, media, or native GPU output is visible.
□ Sliders and buttons update the renderer.
□ Reset, pause, fullscreen, and transport controls work when present.
□ Camera, microphone, MIDI, OSC, or files connect when required.
□ The production build completes and creates a bundle.

After confirming the baseline, read the selected project’s local README.md before changing its renderer, media path, or native integration.

Common installation problems

When the project does not start

npm run dev cannot find Tauri

Confirm that npm install completed inside the selected example folder. Then inspect its package.json scripts.

Rust or Cargo is not found

Install Rust with rustup, restart the terminal, and verify rustc --version and cargo --version.

Native build tools are missing

Install Xcode Command Line Tools on macOS, Microsoft C++ Build Tools on Windows, or the WebKitGTK/build dependencies on Linux.

The camera or microphone does not appear

Grant operating-system permission, restart the application, and use the example’s device refresh control. Close other applications holding the device.

A two-window example reports that its port is in use

Close an older copy of the example or another process using its relay port, then restart the project.

Native wgpu cannot create a surface or adapter

Confirm that the machine has a working Metal, Vulkan, or Direct3D 12 backend and current graphics drivers.
