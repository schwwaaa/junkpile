# Documentation update history

This file records an earlier documentation milestone and has been revised so it does not act as a stale source of current repository totals.

## Earlier milestone

The July 2026 documentation pass established:

- a shared visual language for `index.html` and `docs.html`
- integrated installation/build guidance
- technical comparison between Tauri v1, Tauri v2, and native wgpu
- architecture diagrams
- searchable/filterable example cards
- local README links
- repository audit and documentation standards

At that time, the native documentation represented only the earlier baseline. The repository has since expanded substantially into native media, recording, output routing, runtime infrastructure, A/V capture, and WGSL tooling.

## Current rule

Do not use this historical file to infer the current number of projects or the current end of any track.

Use:

- `docs/examples.json`
- `docs/EXAMPLE_MATRIX.md`
- `wgpu/README.md`
- `docs/ARCHITECTURE.md`

for the current repository state.
