# Screenshot checklist

Store screenshots in `docs/images/` using the project folder name:

```text
docs/images/<project-folder>.png
```

## Capture standard

For each example:

- capture the complete application window or both windows
- keep controls readable
- show a non-default visual state when it demonstrates the input
- avoid covering status indicators with other windows
- record the OS and app version in the pull request or test note
- use consistent dimensions where practical

## Two-window examples

Capture both windows in one image when the relationship is important. For projector-oriented layouts, a second screenshot may show the clean canvas output alone.

## Camera examples

Use a neutral test subject or a generated/video-loop source when privacy is a concern. The screenshot should still demonstrate that a live texture reaches the shader.
