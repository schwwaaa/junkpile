# Screenshot and visual evidence checklist

Each example should eventually include:

- full application at first launch
- controls and renderer visible at normal scale
- strongest representative output
- telemetry/status panel
- input/device selection where applicable
- compiler/error terminal for shader tools
- two-window arrangement for relay, mapping, and output examples
- production bundle or installer evidence

## Native wgpu additions

Capture backend/adapter telemetry, compute/3D visual output, high-resolution/export progress, and any native capture or interop status.

## Naming

```text
docs/images/<collection>-<number>-<short-description>.png
```

Examples:

```text
docs/images/v2-21-projection-mapper.png
docs/images/wgpu-12-fluid-feedback.png
```

Use real output. Do not replace missing runtime evidence with generic stock images.
