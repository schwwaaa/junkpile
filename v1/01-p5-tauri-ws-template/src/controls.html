01 · p5.js WebSocket

HTML controls in one WebView drive a p5.js WebGL shader in a second window through an embedded Rust WebSocket relay.

Controls→WebSocket→Rust relay→Canvas→GLSL
ARCHITECTURE

Two windows, synchronized state

The controls window sends parameter batches. The canvas window requests a complete state snapshot whenever it reconnects, so resizing, reloading, or reopening the output does not reset the visual.
