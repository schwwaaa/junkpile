External shader contract

Use GLSL ES 1.00, declare precision highp float;, provide void main(), write to gl_FragColor, and consume any of the supplied uniforms you need. Unused uniforms are allowed.

u_time · u_resolution · u_hue · u_saturation · u_brightness · u_zoom · u_distortion · u_rotate · u_complexity · u_symmetry · u_glow · u_invert · u_pulse

WHY EXTERNAL FILES?

Shader files can be edited in a dedicated code editor, generated by tools, versioned independently, and hot-swapped without rebuilding Rust. Example 17 later turns this concept into a complete live shader editor.
