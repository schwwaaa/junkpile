Both generations are WebView-first.

The Tauri v2 folders are real v2 ports, but they do not become native Metal, Vulkan, DirectX, or wgpu renderers merely because they use Tauri v2. The graphics in every current example remain JavaScript/WebGL inside the operating system WebView.

Technology families

Choose the part you want to learn.

Each family isolates one graphics or input architecture. Single-window and two-window variants reveal the cost of adding a transport layer.

p5.js family

The quickest path from a creative sketch to a desktop app.

p5.js creates the WEBGL canvas, manages the animation loop, compiles embedded shader strings, and uploads uniforms through a compact creative-coding API.

Explore p5.js →
Raw WebGL family

The browser graphics pipeline with every important step visible.

These examples request a WebGL context, compile and link shaders, create a full-screen quad, locate uniforms, resize the viewport, and issue draw calls without a graphics framework.

Explore Raw WebGL →
External GLSL family

Raw WebGL with shader source kept in a separate file.

The fragment shader lives in shader.frag and is loaded at runtime. This isolates shader authoring from host JavaScript and introduces explicit loading and compile-error handling.

Explore External GLSL →
Webcam family

Live camera capture uploaded into a WebGL texture every frame.

JavaScript requests camera access with getUserMedia, routes the stream through a hidden video element, and uploads each ready frame into a GPU texture for real-time processing.

Explore Webcam →
Feedback family

Stateful image processing with alternating framebuffer textures.

Two framebuffer textures alternate roles. Each frame samples the previous state and webcam texture, writes the next state, displays it, then swaps references.

Explore Feedback →
MIDI family

Native hardware control routed from Rust into a p5.js renderer.

Rust uses midir to enumerate ports and receive messages because Web MIDI support is inconsistent across desktop WebViews. Structured events are then emitted to JavaScript.

Explore MIDI →
OSC family

Network control over UDP for creative software ecosystems.

Rust binds UDP port 9000 with Tokio, decodes OSC packets with rosc, and emits messages into JavaScript, where addresses are mapped to visual parameters.

Explore OSC →

Window topology

Direct state or transported state.

A single-window example is the simplest mental model. A two-window example adds an explicit relay so controls and output can live on different displays.

Single-window architecture

1. User changes a controlslider · button · select
↓
2. Handler writes paramssame JavaScript context
↓
3. Render loop reads statenext animation frame
↓
4. Canvas drawsone Tauri window

Two-window WebSocket architecture

1. Controls windowsends JSON to 127.0.0.1:2727
↓
2. Rust relaybroadcasts to the other client
↓
3. Canvas windowupdates its local params
↓
4. Visual outputindependent display placement

Documentation ethos

No mystery meat architecture.

Every claim is separated by evidence level. “Static reviewed” means the source and configuration were inspected. It does not secretly mean every build, operating system, camera, controller, or network path has been runtime-tested.

Read validation status

Build from a known baseline.

Junkpile keeps graphics, input, transport, and Tauri-generation decisions visible so developers can change one layer without guessing what the others are doing.
